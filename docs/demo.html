CoSpace

AI 编程的联机模式：在你自己的电脑上开一个空间，信任的人一条 ssh 进来，和你用同一个 AI agent。

Host：一条命令装好（Mac 或 Linux）

curl -fsSL https://cospace.jingxuan.uk/host.sh | sh

Mac 需要 Apple 芯片和 macOS 26 或更新；Linux 需要 Docker 和 systemd。装完浏览器自动打开控制台。

Guest：零注册，一分钟上手

curl -fsSL https://cospace.jingxuan.uk/install.sh | sh

打开 host 发来的邀请链接，粘贴一次命令，之后 ssh 空间名 就能进来，claude / codex / grok 直接可用。

CoSpace — Co-op mode for AI coding.

Shared Linux dev spaces on your own Mac or Linux server. People you invite join over plain ssh; claude, codex and grok inside work immediately, on AI quota you provide as host through a gateway on your machine. Your credentials never leave it.

AI 编程的联机模式：在你自己的电脑上开一个空间，信任的人一条 ssh 进来，和你用同一个 AI agent。

Host · one command

Apple Silicon Mac (macOS 26+) or a Linux server with Docker. Installs the daemon, registers it as a service and opens the console.

curl -fsSL https://cospace.jingxuan.uk/host.sh | sh

Guest · one command, no account

Installs the cospace tool (alias co). Then paste the one-time pair command your host sends you and run ssh <space>.

# macOS / Linuxcurl -fsSL https://cospace.jingxuan.uk/install.sh | sh
# Windows PowerShell (needs OpenSSH Client)irm https://raw.githubusercontent.com/JingxuanKang/cospace/master/docs/install.ps1 | iex
